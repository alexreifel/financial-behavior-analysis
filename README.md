# Financial Behavior Analysis

This project examines the gap between financial confidence (how well individuals believe they understand their finances) and financial competence (how well they actually understand them).
The goal is to assess whether overconfidence or underconfidence influences financial behavior, and whether behavioral patterns can be predicted from self-reported confidence levels.
